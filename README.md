# P2-Project
# **Project Name: Mitigating Exam Stress**
## **Final ProblemStatement**
There is a lack of a centralized, structured, and course-specific system that supports students in understanding exam requirements and organizing their study process, based on specific semester syllabi, to reduce uncertainty, procrastination, and exam-related stress.
