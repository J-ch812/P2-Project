# P2-Project
# **Project Name: Mitigating Exam Stress**
## **Final ProblemStatement**
There is a lack of a centralized, structured, and course specific sys-
tem that supports students in understanding exam requirements,
organizing their study process, and maintaining progress through-
out the semester and exam period in order to reduce uncertainty,
procrastination, and exam related stress.
